В Lampara при подключении поиска торрентов через jackett на rutor столкнулся с тем что он передает параметр category из-за которого jackett ничего не ищет
этот JS это исправляет; 
Но передача category (нужна для фильтрации выдаче по видам торрентов фильмы/сериалы/софт и т.д.) при его подключении для всех поисков отключится
устанавливать как плагин в лампара
